# Study Companion

Interactive learning, concept explanations, practice quizzes, and assignment milestone planning for teens with academic integrity guardrails.

## Overview

Study Companion is a private, local-first learning companion designed specifically for teenagers (ages 13–17). It empowers students to understand challenging concepts in science, math, literature, and history through Socratic explanations, interactive self-quizzing, and digital flashcards—all while strictly protecting student privacy on local models.

## Key Capabilities

- **Concept Explanations**: Break down complex concepts using relatable analogies and step-by-step walkthroughs.
- **Practice Quizzes**: Test knowledge with self-paced practice quizzes featuring instant, constructive feedback.
- **Digital Flashcards**: Create flashcard decks for vocabulary, historical events, and scientific formulas.
- **Assignment Milestone Planning**: Decompose large school projects into achievable study chunks.
- **Writing Feedback**: Provide guidance on thesis statements, outlines, and grammar without ghostwriting.

## Safety & Academic Integrity

Study Companion is an educational tutor, not a homework shortcut. Under the **Academic Integrity Guardrail** (`complete_graded_work`), it strictly refuses to write student essays, solve graded homework assignments, or answer active test questions.

## Example Terminal Usage

```bash
yarvelle run --agent study-companion "Quiz me on 5 practice questions for 9th grade biology cell mitosis."
```
